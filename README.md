# Card Matching Game

A fully responsive frontend card matching game built with React. Players match pairs of cards within a time limit while tracking the number of moves. The game features a start animation triggered by a play button, enhancing the user experience before gameplay begins.

## Features

- Interactive card matching logic with state management
- Timer countdown to challenge players
- Move counter to track performance
- Animated play button to initiate the game
- Responsive design for desktop and mobile
- Modular React components for scalability

## Tech Stack

- React
- CSS
